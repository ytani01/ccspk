## きっかけ

利用者から「読み間違いが多い」と相談があった（2026-09-28）。大文字だけの語を
1 字ずつ読む（`TODO` → ティイオオディイオオ）、「〜」を読まない、数字と単位の
間のスペースで区切る（`180 字` → ヒャクハチジュウ、ジ）、などがあった。

## やったこと

- 過去の返答 1,869 件の読み上げる範囲から、大文字の語・拡張子・英字と数字の
  組・記号を数え、エンジンの読み（`audio_query` の `kana`）と並べた。
  一覧を見て、利用者と直す語と読みを決めた
- VOICEVOX のユーザー辞書に 7 語を登録した: `TODO` → トゥードゥー、`README` →
  リードミー、`CLAUDE` → クロード、`JSON`・`json` → ジェイソン、`LICENSE` →
  ライセンス、`MELPA` → メルパ。`HUD` は登録しないと決めた。
  辞書の元を `voicevox/user_dict.json` に置き、`.gitignore` で許可した
- `hooks/speak-response.py` の `to_speech` で:
  - 「〜」「～」「→」を「から」にし、前後のスペースも消す
  - 数字に挟まれた半角「~」を「から」にする（取り消し線や `~/` は変えない）
  - 数字（全角も）の直後のスペースを、同じ行で日本語が続くときだけ消す
  - それぞれのテストを `demo()` に足した
- 利用者の依頼で `docs/UsersGuide.md` を新しく作り、辞書の読みの確かめ方・
  登録・一覧・削除・書き出し・戻し方と、`/docs`（ブラウザ）での登録を書いた。
  README からはリンクと、整形の箇条書きの 1 行だけにした
- 「/」は読まないままにした（パスでは困らない）

直す前と後の読みは `archives/agents/TODO-005/readings.md`（59 語）。
