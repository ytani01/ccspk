## 順序を変えたことによる、TODO 以外の入力の変化

困るものは見つからなかった。変わるのは、数字と「~」の間に `` ` ``・`*`・`>` だけがある形で、どれも
「から」と読むほうが自然。

| 入力 | 出力 |
|------|------|
| `` 1`~`4 `` | `1から4` |
| `` `1` ~ `4` 秒 `` | `1から4秒` |
| `**2**~**3** 行` | `2から3行` |
| `2 >~ 3` | `2から3` |

変わらないもの（ホームのパス、コードの中の `~`、片側だけ数字）: `` `~/a` 1 `` → `/a 1`、`` 2`~/x` `` → `2/x`、
`` `a~b` 1 `` → `ab 1`、`` `x`~`1` `` → `x1`、`` `~1` `` → `1`、`1 -> 2` → `1 - 2`、`x ~> 3` → `x 3`
