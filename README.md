# ccspk

Claude Code の返答を、手元の VOICEVOX（既定は夜語トバリ・明るい）で読み上げるフック。
長い返答は要約し、英文の返答は日本語に訳して読む。

https://github.com/user-attachments/assets/78a4d7cf-f9b8-4bff-bdf5-e12a925c588b

返答の読み上げ・長文の要約・英文の翻訳のデモ（音が出ます。待ち時間は詰めてあります）。音声: VOICEVOX:夜語トバリ

## 1. 特徴

- **長い返答は要約して読む。** `ccspk summary on` にすると、180 字を超える返答は Claude に 180 字ほどに要約させてから読む。
  結論や、利用者に頼んでいること・決めてほしいことを優先して残す
- **英文の返答は日本語に訳して読む。** `ccspk translate on` にすると、英文の返答は Claude に日本語へ訳させてから読む。
  英語で作業しても、耳で聞いて分かる
- 要約・翻訳では、「今日」「辛い」のように文脈で読みが分かれる単語は、Claude にひらがなで書かせるので、読み間違えにくい
- 読み間違いを自分で見つけて直す。読み上げた文から英単語と漢字の単語を拾い、エンジンの読みを Claude に
  判定させ、誤っていれば正しい読みで辞書に登録する。返答のたびに裏で動くので待たされない。
  自動で登録した単語は `ccspk dict auto` で見直し、まとめて消せる
- 返答を全部は読まず、冒頭の 180 字ほどを読む。コードブロックは「コード省略」と読み、表は飛ばす
- 1 文目の前半ができたらすぐ鳴らし、残りは鳴らしている間に合成する
- 合成は手元のエンジンで行う。外に送るのは、読み間違いの点検で Claude に渡す単語・読みと、その単語の前後 30 字だけ
  （要約・翻訳を入れたときは、要約・翻訳させる返答も）
- 合成と再生は子プロセスに任せるので、Claude Code を待たせない。鳴らせない環境では、そのことを覚えて、
  次からは確かめもせずに終わる

## 2. 主な機能

- 返答の最後の文章、ツールを呼ぶ前などの途中の文章、`AskUserQuestion` の質問の文を読み上げる。
  再生中に次の文章が来たら、前の再生を止めて新しいほうを読む（`ccspk queue on` なら止めずに来た順に読む）
- `ccspk stop` で、鳴っている読み上げを止める
- `ccspk dict` で、読み間違える単語を VOICEVOX の辞書に手で登録する
- `ccspk status` で、読み上げが止まったままになった理由を見る
- `ccspk summary` で、長い返答を要約して読むかを切り替える
- `ccspk queue` で、前の読み上げを止めずに来た順に読むかを切り替える
- `ccspk translate` で、英文の返答を日本語に訳して読むかを切り替える
- `ccspk speaker` で、読み上げの話者を変える
- `ccspk volume` で、読み上げの音量を変える

## 3. 注意事項

裏で `claude -p` を呼ぶので、Claude Code の作業とは別にトークンを使う。1 回の目安は次のとおり
（2026-09-29 に測った。入力はキャッシュの読み書きを含む）。

| 使うところ | モデル | いつ動くか | 1 回のトークン量 |
|------------|--------|------------|------------------|
| 読み間違いの自動の点検 | Opus | 返答が終わるたび、まだ点検していない単語があるとき（切る設定は無い） | 10〜30 単語で入力 約 7,000・出力 100〜450 |
| 要約 | Sonnet | `ccspk summary on` のとき、180 字を超える返答で。途中の文章や質問も要約する | 入力 約 8,000・出力 約 150 |
| 翻訳 | Sonnet | `ccspk translate on` のとき、英文の返答で（要約する長さなら要約だけ）。途中の文章や質問も訳す | 入力 3,000〜6,500・出力 約 250 |
