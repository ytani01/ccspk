# ccspk

Claude Code の返答の冒頭を、手元の VOICEVOX（夜語トバリ・明るい）で読み上げるフック。

## 1. 特徴

- 返答を全部は読まず、冒頭の 180 字ほどを読む。コードブロックは「コード省略」と読み、表は飛ばす
- 1 文目の前半ができたらすぐ鳴らし、残りは鳴らしている間に合成する
- 合成は手元のエンジンで行うので、返答が外に送られることはない
- 合成と再生は子プロセスに任せるので、Claude Code を待たせない。鳴らせない環境では、そのことを覚えて、
  次からは確かめもせずに終わる

## 2. 主な機能

- 返答の最後の文章、ツールを呼ぶ前などの途中の文章、`AskUserQuestion` の質問の文を読み上げる。
  再生中に次の文章が来たら、前の再生を止めて新しいほうを読む
- `ccspk stop` で、鳴っている読み上げを止める
- `ccspk dict` で、読み間違える単語を VOICEVOX の辞書に登録する
- `ccspk status` で、読み上げが止まったままになった理由を見る
